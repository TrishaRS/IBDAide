IBD Aide — Wireframes · 6 Core Screens

Low-fidelity layout reference for iOS (SwiftUI) and Android (Compose). Structure and hierarchy are normative; visual styling is not — each platform uses native components (SF Symbols / Material 3). Every screen sits behind the biometric app lock (FR-13). Primary content fits without scrolling on ≥6.1″ displays (NFR-4).
